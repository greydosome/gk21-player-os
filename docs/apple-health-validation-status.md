# 건강 연동 검증 상태

최신 구현 및 설정은 [무료 건강 연동](free-health-shortcuts.md)을 참고한다.

- 수면·운동 수신을 각각 켜고 끌 수 있다.
- 기존 기록 통합은 APPLE_HEALTH_RECORD_SYNC_ENABLED로 제어한다.
- 실제 수면 HTTPS 저장과 건강 앱 열기 자동화 전송을 검증했다.
- 실제 운동 일괄 저장과 재전송 중복 방지를 검증했다.
- 수면은 수집 시간을 기존 정수 시간 칸으로 반올림한다. 건강 앱 표시와의 분 단위 일치를 주장하지 않는다.
- Watch 종료 이벤트 및 잠금 상태 실행은 추가 기기 검증이 필요하다.
- 개인 실측 기록과 인증정보는 공개 검증 문서에 포함하지 않는다.
