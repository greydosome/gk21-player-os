# 무료 건강 연동: 기존 기록 통합

Apple 건강의 수면 요약과 무료 Actions 앱의 운동 기록을 기존 GK21 기록 칸으로 반영한다.
개인 실측값, 화면 캡처, 전송 키, 생성된 단축어는 공개 소스에 포함하지 않는다.

## 저장 규칙

- 수면 시간은 기상 날짜에 귀속하고 기존 정수 시간 입력에 반올림한다. 누락된 수면은 0으로 덮어쓰지 않는다.
- 수면 수집기는 겹친 구간을 한 번만 계산한다. 건강 앱의 출처 우선순위와 분 단위 표시를 그대로 재현한다고 보장하지 않는다.
- 운동은 세션 전체 활동 시간을 한국 시간대 종료 날짜에 반영한다. 같은 세션 재전송은 중복 합산하지 않는다.
- 알려진 운동 종류는 기존 운동 항목으로 연결한다. 근력 운동의 신체 부위나 세부 종목은 기기 기록만으로 추정하지 않는다.
- 확인된 종목은 record_workout_type 및 record_detail로 명시적으로 매핑할 수 있다.
- 직접 입력하거나 수정·삭제한 기록을 자동 수집이 되돌리지 않는다.
- 오래 열린 화면의 저장 요청은 health_record_revision으로 새 수집 기록을 보호한다.
- 별도 건강 카드 대신 기존 운동·수면 입력을 사용한다.

## 서버 적용

1. 데이터베이스를 백업한다.
2. sql/migrations/2026-11-10_health_existing_records.sql을 적용한다.
3. APPLE_HEALTH_ENABLED, APPLE_HEALTH_SLEEP_ENABLED, APPLE_HEALTH_RECORD_SYNC_ENABLED를 켠다.
4. 별도 건강 코칭을 사용하지 않으면 APPLE_HEALTH_COACHING_ENABLED는 끈다.
5. backend/frontend를 빌드·재시작한다. 과거 요약은 자동으로 일괄 복사하지 않는다.

인증된 HTTPS daily/export 수신 경로는 날짜·수면 합계 또는 운동의 최소 필드만 받는다.
개인 전송 키는 환경 파일로 공급하고 저장소·URL·로그에 넣지 않는다.

## 아이폰 단축어

- scripts/build_sleep_sync_shortcut.py: 수면 수집 → 날짜별 JSON → daily API.
- scripts/build_workout_sync_shortcut.py: 최근 운동 조회 → 최소 필드 추출 → export API.
- 두 생성기는 --token-file로 비공개 키 파일을 읽는다. 생성 파일에는 키가 들어가므로 절대 공유하지 않는다.
- 생성 파일은 Mac 단축어 CLI로 서명한 후 개인 기기에만 설치한다.
- 수면은 ‘건강 앱이 열릴 때 → 즉시 실행 → GK21-Sleep-Auto’ 자동화를 사용할 수 있다.
- 운동은 ‘Apple Watch 운동이 종료될 때 → 즉시 실행 → GK21-Workout-Auto’를 사용할 수 있다.
- 건강 데이터 읽기·전송 권한은 기기에서 직접 검토한다. 잠금 상태의 HealthKit 읽기와 매일 정시 무인 수집은 보장하지 않는다.

## 검증

로컬 임시 PostgreSQL에서 36개 백엔드 검사와 frontend 타입 검사·빌드를 통과했다.
중복 전송, 자정 경계, 수면 반올림, 수동 수정·삭제 및 오래 열린 폼 저장 보호를 검사한다.
수면은 실제 기기의 수동 실행과 건강 앱 열기 자동화에서 HTTPS 수신·기존 칸 저장을 확인했다.
운동은 실제 기기 일괄 저장·재전송 중복 방지를 확인했다. 실제 Watch 종료 이벤트와 잠금 상태 실행은 미검증이다.
